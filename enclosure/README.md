# enclosure

Premiere version d'un **mini ecran de Stevenson** pour la sonde, a imprimer en 3D.

- `stevenson-shelter-v1.scad` : modele OpenSCAD (V8), adapte du plan traditionnel a l echelle de la sonde.
  Volume interieur 110 x 90 x 110 mm, caisson exterieur 130 x 110 x 130 mm, 10 lames par face
  (110 x 8 x 4 mm, inclinees a 40 degres, pas de 11,2 mm), exterieur toujours plus bas sur les quatre faces.
- `stevenson-reference-plan.jpg` : page de reference du plan traditionnel (« La construction d une station
  meteo »). Document tiers : a garder dans ce depot prive, a ne pas publier tel quel.

Etat : premier jet, non imprime ni teste. Le but est de limiter l echauffement solaire du capteur
(variations brutales de temperature observees en plein apres-midi) tout en gardant une bonne circulation d air.
